# Claude Code skills

Skills for maintainers working in this repo. Claude Code loads only folders that contain a `SKILL.md`, so this file is for people.

| Skill | Use it to |
| --- | --- |
| [microsoft-writing-style-guide](microsoft-writing-style-guide/SKILL.md) | Write and review content to the Microsoft style guide. |
| [support-report](support-report/SKILL.md) | Get a short support status and a draft for the contributor sync Teams chat. Read-only on GitHub. |
| [support-sweep](support-sweep/SKILL.md) | Triage open issues and discussions waiting on maintainers into a review page, then post replies a maintainer approves. |

The support skills need `gh` signed in and Node.js. They run from the repo root.
