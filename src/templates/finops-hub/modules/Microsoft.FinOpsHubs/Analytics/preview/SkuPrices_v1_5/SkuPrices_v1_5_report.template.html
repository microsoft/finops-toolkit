Scenarios

History. Both SKU Price tables hold all 14 months: one row per run of months with an unchanged price. Rows start a new row when that price type changes; Columns start a new row when any price on the row changes. Current prices have no effective end.

Cost and Usage join. Costs SkuPriceId doesn't match the price sheet, so cost scenarios use CostsWithSkuPriceIdv2: a copy of Costs with SkuPriceIdv2 looked up by price type, meter, offer, and term. Effective-dated prices are spread over the months they were in effect so each charge matches its month exactly, with no range join and no duplicated cost rows. Today's monthly table needs no spreading.

Units. PricingUnit is empty on ftk-dev (no PricingUnits open data), so price sheet prices are per block (e.g., per 100 hours). Cost scenarios divide by the block size and use a price only when its unit matches the charge's PricingUnit.

Not testable with this data: the 4 PR 2595 queries on announced price changes and quantity tiers, negotiated savings plan discount (savings plan list price is dropped on ingestion), multiple currencies, consumption currency.
